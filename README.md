# WigsStock · אפליקציית ספירת מלאי (Inventory Barcode Scanner)

אפליקציה קטנה וזריזה לספירת מלאי של ~20,000 פאות מול קובץ **גוגל שיטס**.
כל פאה = ברקוד ייחודי (5 ספרות). העובדות סורקות את הפאות שנמצאות פיזית בחנות,
והאפליקציה עושה **התאמה (reconciliation)** מול הסטטוסים שבשיטס.

בלי התקנה, בלי שרת, בלי תלויות — קובץ HTML אחד שרץ בדפדפן ועובד גם בלי אינטרנט
אחרי הטעינה הראשונה.

---

## מה זה עונה

| מצב בשיטס | נסרק פיזית? | קטגוריה | משמעות |
|---|---|---|---|
| `in-stock` | ✅ | **תקין** | קיים כמו שצריך |
| `in-stock` | ❌ | **חסר** | אמור להיות בחנות, לא נמצא (כנראה נמכר/אבד ולא עודכן) |
| כל סטטוס אחר (`sold`, `returned`…) | ✅ | **בחנות אך מסומן אחרת** | פיזית בחנות אבל רשום נמכר → צריך להחזיר ל-`in-stock` |
| לא קיים בשיטס | ✅ | **ברקוד לא מוכר** | נסרק אבל אין לו שורה בקובץ |
| — | 🔁 פעמיים+ | **כפילות** | נסרק יותר מפעם אחת |

---

## איך משתמשים

1. פותחים את `index.html` בדפדפן (מחשב או טלפון). מומלץ להעלות ל-GitHub Pages כדי לפתוח מכל טלפון.
2. **מלאי** → מייצאים מגוגל שיטס ל-CSV (`קובץ ← הורדה ← CSV`) וטוענים. העמודות ברקוד/סטטוס מזוהות אוטומטית.
3. **סריקה** → סורקים. שלוש דרכים:
   - **סורק ברקוד חיצוני** (USB/בלוטות') — הכי מהיר ואמין. סורקים והברקוד נכנס לבד.
   - **מצלמת הטלפון** — כפתור "סרוק עם המצלמה" (Chrome על אנדרואיד).
   - **הקלדה ידנית** + Enter.
   - כל סריקה נותנת משוב מיידי: 🟢 תקין · 🟠 מסומן אחרת · 🔴 לא מוכר · 🔁 כפילות (עם צליל ורטט).
4. **דוח** → סיכום חי + פירוט לכל קטגוריה.
5. **ייצוא** → CSV: דוח מלא / עדכוני סטטוס מוצעים לשיטס / סריקות גולמיות לגיבוי.

**כמה עובדות במקביל:** כל מכשיר סורק לבד, בסוף מייצאים "סריקות גולמיות" וממזגים בלשונית הייצוא.

## בדיקה לפני מלאי אמיתי
`test-barcodes.html` מייצר ברקודי Code 128 להדפסה/מסך, שתואמים ל-`sample-inventory.csv`. ככה בודקים את כל הזרימה עם דוגמה.

## למה לא כותבים כל סריקה ישר לגוגל שיטס (ארכיטקטורה)

זה **local-first**: כל סריקה נשמרת מיידית ב-`localStorage` של המכשיר — אין המתנה לרשת,
עובד גם בלי קליטה, ואין הגבלות קצב. סנכרון לגוגל שיטס קורה **פעם אחת בסוף**, דרך ייצוא CSV.
כתיבה ישירה של 20K סריקות ל-Sheets API הייתה איטית ומוגבלת בקצב.

אם בעתיד רוצים **תצוגה חיה משותפת** בין כמה מכשירים (בלי מיזוג ידני), מוסיפים שכבת backend
דקה — למשל **Cloudflare Worker + KV/D1**: כל סריקה נשלחת ל-Worker, וכל המכשירים רואים אותו מצב.
הסנכרון לגוגל שיטס נשאר צעד נפרד בסוף. זה הצעד הבא, לא נדרש לגרסה הראשונה.
